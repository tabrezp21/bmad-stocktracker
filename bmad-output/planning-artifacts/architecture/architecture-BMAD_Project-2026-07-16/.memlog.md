- (decision) AD-1 Design Paradigm: Single-module layered script (entry-point -> orchestrator -> adapters). Binds all. Prevents: mixing I/O and domain logic in same function. Rule: all external I/O (yfinance, plyer, file writes) lives in adapter modules; the orchestrator loop calls only pure functions and adapter interfaces.
- (decision) AD-2 Language & Runtime: Python 3.10+ (Windows, CPython). Binds all modules. Prevents: use of 3.10+ syntax features in environments < 3.10. Rule: no walrus operator or match-case unless project baseline is confirmed >=3.10; use union type hints (X | Y) only if target is >=3.10.
- (decision) AD-3 Configuration boundary: config.json is the single source of truth for all user-tunable values (threshold, interval, simulation_mode, test_price). Binds orchestrator and all adapters. Prevents: hardcoded magic numbers in source. Rule: no tunable value appears as a literal anywhere except config.json and its loader.
- (decision) AD-4 Error isolation: all adapter calls are wrapped; failures return None or raise a typed exception caught by the orchestrator. Binds fetch adapter, notify adapter, log adapter. Prevents: unhandled exceptions propagating to __main__. Rule: the orchestrator loop must never exit due to an adapter error; retry after CHECK_INTERVAL.
- (decision) AD-5 Scheduling ownership: market-hours guard lives exclusively in the orchestrator, not in adapters. Binds orchestrator. Prevents: adapters silently skipping work or duplicating time logic. Rule: adapters are always-on; the orchestrator decides whether to call them.
- (decision) AD-6 Simulation mode: when simulation_mode=true the fetch adapter returns test_price without touching the network. Binds fetch adapter only. Prevents: live network calls during tests. Rule: simulation branch is inside the fetch adapter, invisible to the orchestrator.
- (version) yfinance: latest stable (>=0.2); plyer: >=2.1; Python: >=3.10 (Windows 10/11)
- (assumption) Host clock is set to IST. plyer toast works on Windows 10/11. yfinance free tier is available.
